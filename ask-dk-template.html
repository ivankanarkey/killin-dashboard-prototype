WWWWWH

Who

What

Why

What does it get us, or what trouble does it avoid?
What else does it tie into?
When
Is there a deadline? Is it HARD (external or contractual) or SOFT (internal)?
How long will it take?
What depends on it?

Where does it end up?
Where does it happen?
How

What does it cost, & what does it commit us to?

Rules

Do
  • Ask first. Detail after.
  • Use the questions that fit the ask. Skip the rest.
  • Partners by their proper name: Wrybill Robotics, Lincoln Agritech.
  • Plain words. No jargon.
  • Link files where you can. If there is no link, say where the file is.
Never
  • "I'm here if you need me" · "Let me know if you need anything."
  • Blaming people instead of describing the job.
Colour rule: purple = action required · red = blocked · orange = underway · green = decided only · turquoise = completed.
